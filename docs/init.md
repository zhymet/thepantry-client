1. Create initial vite project.
```
npm create vite@latest thepantry-client
o  Select a framework:
|  React
|
o  Select a variant:
|  TypeScript + React Compiler
|
o  Which linter to use?
|  ESLint
|
o  Install with npm and start now?
|  Yes
```

2. Install dependencies.
```
cd thepantry-client
npm install
```

3. Run the client.
```
npm run dev
```
